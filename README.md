## About

I've spent most of the last decade at the frontend of two very different open-source
communities: a workplace collaboration platform ([Mattermost](https://mattermost.com)) and
a Web3 governance ecosystem ([Boardroom.io → Agora](https://agora.xyz)). At Boardroom.io I
was the first engineering hire, turning a hackathon prototype into a governance hub serving
**350+ DAOs and 50K+ monthly active users** — including Optimism, ENS DAO, and Uniswap.

I care about performance work that's measurable: cutting retained memory 85% on channel
switches, first-paint times by over 80%, API response times by 80% on a rebuilt proposal
pipeline. Most of that work is public — the numbers below link straight to the merged PRs.
